# Barbearia do Bairro

MVP de aplicativo para organizar serviços e agendamentos de uma barbearia local.

## Objetivo

Permitir que o cliente consulte serviços, escolha uma data e horário e confirme ou cancele um agendamento.

## Escopo do MVP

- Tela de entrada/login (demonstração)
- Consulta de serviços
- Seleção de data e horário
- Confirmação do agendamento
- Cancelamento do agendamento
- Interface com foco em acessibilidade

## Tecnologias

- Flutter / Dart
- Arquitetura simples em camadas para o MVP
- Dados fictícios para demonstração

## Como executar

```bash
flutter pub get
flutter run
```

> O MVP utiliza dados fictícios nesta primeira versão. A integração com Supabase pode ser adicionada em uma etapa posterior.
